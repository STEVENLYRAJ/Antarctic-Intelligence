# Page structure (v2, 2026-11-20)

| Route | Purpose | Data |
|---|---|---|
| `/` | Seven-chapter documentary narrative with a chapter rail (≥ 1536 px): **01 Discover Earth → 02 The cryosphere (4 sourced facts) → 03 Journey south (scroll-driven camera to the pole) → 04 The continent (NASA MODIS mosaic + 8 region cards that open the explorer) → 05 The data (47-year extent record + archive stats read at build time) → 06 Machine intelligence (live model cards) → 07 Research & method (architecture) → CTA** | API (4 latest endpoints), `climate_series.json`, `globe/catalog.json` (counts), `imagery/*.jpg` |
| `/explore` | 3D Cesium explorer. Nine camera destinations (Global, Antarctica, Peninsula, Ross, Weddell, East, West, South Pole, Southern Ocean); region intelligence panel with the regional values each API actually provides; 28 layers in groups; **timeline** with play/pause/step for every time-enabled layer; drift arrows; per-layer info (units, coverage, source, method); search (destinations, 22-place gazetteer, "lat, lon"); MODIS true colour by date; graticule; full screen; keyboard shortcuts (/ L Space ←→ F); deep links `?region=` and `?layer=` | `/layers/{sic,t2m,sar,anom}/latest` → `/globe/...png`; `/data/globe/catalog.json`; NASA GIBS |
| `/intelligence` | 01 Monthly records (11 variables, anomaly/absolute, years, NSIDC sectors, second record, seasonal cycle, regional comparison, structured metadata block) · 02 This year vs history (daily extent 1978–2025 and daily t2m 2014–2026 against the reference envelope) · 03 Then and now (polar compare slider, any two years, any month) · 04 Globe layer shortcuts | `climate_series.json`, `daily_series.json`, `globe/catalog.json`, `imagery/continent_bluemarble.jpg` |
| `/models` | Index of the four modules with live headline values | API |
| `/models/ml-01` … `ml-04` | Sticky module switcher + scroll-spy index. Nine sections: introduction, objective, data inputs, methodology, interactive visualisation, results & metrics, evaluation (skill-vs-baseline chart + deployed model + provenance), limitations, research interpretation | See FRONTEND_API_INTEGRATION.md |
| `/data` | Dataset catalogue: 14 datasets with "used by" showing exactly where each appears on the site | `config/datasets.ts` |
| `/research` | Eight insights computed on load (ERA5 extent and temperature extremes, daily-record extremes, winter drift speed, ocean temperature, GLORYS thickness, ML-04 flag rate) | `climate_series.json`, `daily_series.json`, `/api/ml04/monthly-summary` |
| `/about` | Vision, objectives, roadmap (Phases 2–4 planned only), architecture, stack, SDG 13/14, disclaimer | static |
